# MeetVox Card — Privacy Policy

The published privacy policy for the [MeetVox Card](https://apps.apple.com/) iPhone app,
served as a single static page via GitHub Pages.

**Live:** https://antoine-debroye.github.io/meetvox-card-privacy/

This repository is public because Apple requires the policy to be reachable
without authentication. It contains no application code — the app itself lives
in a private repository.

To update the policy, edit `index.html` and push; GitHub Pages redeploys
automatically. Update the "Last updated" date at the top and in the footer.
